# 첫 접속과 휴식 경험 개선 결과

2026년 11월 8일. 기준 v72에서 첫 개선을 진행했다. 휴식의 가치를 높이는 작업이며 전체 기획서의 모든 항목을 완료한 것은 아니다.

## 발견과 수정

| 문제 | 수정 | 검증 |
| --- | --- | --- |
| 다른 버튼을 눌러도 소리 시작 가능 | 명시적 소리 조작에서만 시작 | 신규 접속·기능 안내 중 재생 호출 0, 직접 시작 후 재생 |
| 첫 안내를 다시 볼 경로 없음 | 설정에 조작 방법 추가 | 안내 재열기·닫기·Esc |
| 안내를 다 읽어야 시작 가능 | 첫 화면에서 소리 켜고 머무르기 | 두 번째 설명 화면을 거치지 않고 시작 |
| 풍경·날씨·음량 초기화 | 검증된 값만 동일 기기에 저장·복원 | 재방문·잘못된 JSON·범위 초과·저장소 차단 |
| 10분 무동작이 소리까지 중단 | 공유 접속 종료와 휴식 유지 분리 | 시간 경과 후 비차단 안내, presence 중단, 소리 상태 유지, 조작 후 재연결 |
| 바다만 보기에서 음소거 접근 어려움 | 최소 소리 버튼과 메뉴 복원 버튼 유지 | 전체 화면에서 음소거·메뉴 복귀 |
| 소리 오류가 접힌 설정 안에만 표시 | 화면 공통 오류 안내 | 재생 실패·재시도 성공 |
| 설정 모달에서 키보드 이탈 가능 | 열린 설정 내부 Tab 순환 | Tab·Esc·포커스 복귀 |
| 접속 설명이 항상 1초 공유로 안내 | 상태에 따른 1~5초와 휴식 중 중단 설명 | 코드와 안내 대조 |

휴식 정책: 기존 10분은 공유 연결·공유 자리 점유를 정리하는 기준으로 유지한다. 더 이상 화면을 막는 종료 대화상자를 띄우거나 바다 소리를 멈추지 않는다. 포인터 클릭·키보드·휠 조작 시 연결을 재개한다. 단순 마우스 이동만으로 휴식 상태에서 재접속하지 않는다. sendBeacon 실패 시 자리는 서버 만료 정책으로 정리된다. 선장 이탈의 정박·승계는 기존 서버 동작을 유지한다.

소리 정책: 재방문 시에도 이용자가 직접 켠다. 음량·풍경·날씨는 복원한다. 토스 어댑터가 있는 경우 백그라운드에서는 기존 정책대로 소리를 멈추고, 복귀 시 이전에 켰던 소리만 재개한다. 휴식 모드는 백그라운드 재생 지원을 약속하는 기능이 아니다.

## 검증 범위

- TypeScript, 기존 세션·접속·인증 전 요청·행동 상태 회귀 검사, 신규 휴식·설정 검사를 실행한다.
- 토스 네이티브 저장 허용 목록에 환경 설정 키를 추가하고 기존 9개 어댑터 검사를 실행한다.
- Chromium 모바일 390×844에서 첫 접속·재방문·음소거·도움말·휴식과 재연결을 확인한다.
- 320px 모바일, 844px 가로 화면, 1180px 데스크톱에서 설정 화면을 확인한다.
- API와 오디오 재생 호출을 모의하며 WebGL을 끈 브라우저 검사다. 실제 서버에 가짜 인원을 만들지 않는다.
- 토스용 개발 화면에서도 앱 숨김·복귀, 음소거 유지, 설정 키보드 조작, 저장소 접근 차단 시 기본 동작을 모의 검증했다.
- 재생 호출의 제어를 확인한 것이며 음원의 청감·루프 이음새·실제 토스 오디오·두 명 이상의 동시 탑승 검증을 대체하지 않는다.

브라우저 재현: 개발 서버 실행 후 `PLAYWRIGHT_MODULE=/path/to/playwright SEA_TEST_OUTPUT=/tmp/little-sea-ux01 node tests/browser/sea-rest-flow.cjs`. Chromium 위치는 CHROMIUM_PATH, 주소는 SEA_TEST_URL로 지정할 수 있다. 토스용 개발 서버에서 같은 환경 변수로 tests/browser/sea-native-rest-flow.cjs를 실행하면 복귀·저장소 차단 검사를 재현할 수 있다. 추가 설치 없이 기존 Playwright 환경을 사용했다.

## 다음 검증

1. 토스 실제 기기에서 음원·통화·화면 잠금·앱 복귀와 저장 복원.
2. 두 명 이상으로 자리 해제·배 선장 이탈·재탑승 확인.
3. 밤 풍경의 편안함, 휴식 시작 시간, 소리 품질을 소규모 사용자 관찰로 확인.
4. 기획서의 디자인 시스템 전체 정합성·자산 권리·수익화 정책 검토.

실제 사용자 반응과 월 비용은 측정 전이며 숫자를 추정해 완료로 기록하지 않는다. 토스 콘솔 업로드와 심사 요청은 이 작업에 포함하지 않는다.
