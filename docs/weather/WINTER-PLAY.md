# 눈 모드: 스키·썰매와 작은 크리스마스

작성: 2026-11-23. 기존 바다 그래픽과 SVG 캐릭터를 유지하면서 눈 모드에만 계절 이동과 장식을 적용한다.

## 이용 경험

- 눈 덮인 해변과 섬에서는 걷는다. 얼어붙은 바다에 들어가면 기본 스키로 전환한다. 별도 획득·결제는 필요 없다.
- 소유·장착한 기존 뗏목은 나무 썰매로 표시한다. 눈이 그치면 같은 장비가 기존 뗏목으로 돌아온다.
- 눈 모드에서는 수영 모션·튜브·잠수 진입을 사용하지 않는다. 잠수 도중 눈으로 바뀌면 수면 위로 올라오고 예약된 잠수도 취소한다.
- 눈 모드에만 겨울 선물상자를 발견할 수 있다. 탐험 또는 내 정보의 ‘겨울 선물 찾기’를 누르면 상자로 이동한다. 가까이 도착한 뒤 ‘선물 열기’를 눌러 루돌프 산타 썰매를 한 번 획득한다.
- 획득 즉시 장착한다. 탐험·내 정보의 ‘겨울 이동 장비’에서 기본 스키, 나무 썰매, 루돌프 산타 썰매를 선택한다. 수집함에도 획득한 루돌프 썰매가 남는다.
- 장비 기록은 기존 수집품과 같이 이 브라우저/기기에 저장한다. 오래된 저장 데이터에도 겨울 필드를 기본값으로 보충한다. 눈이 그쳐도 소유 기록은 남고, 겨울 장비 선택은 눈 모드에서 이용한다.

## 이동 규칙

| 상황 | 속도 (기준 월드 단위/초) |
| --- | --- |
| 땅 걷기 | 2.4 |
| 기본 스키 | 3.0 |
| 나무 썰매 | 3.8 |
| 루돌프 산타 썰매 | 5.3 |

루돌프는 나무 썰매 대비 약 39.5% 빠르다. 이 보너스는 얼어붙은 바다에서만 적용하고, 육지·일반 날씨에는 적용하지 않는다. 두 풍경에서 같은 속도 비율을 적용한다. 이동은 기존 프레임 루프를 사용하며 통신·DB 쓰기 주기를 늘리지 않는다. 다른 방문자도 눈 풍경에서 겨울 장비로 보이며, 루돌프 이동을 따라가는 보간 상한을 보정한다.

## 그래픽과 UI

- 기존 캐릭터와 같은 SVG 스타일로 스키·폴, 곡선 러너의 나무 썰매, 빨간 코와 뿔이 있는 루돌프 및 산타 썰매를 직접 그렸다.
- 두 섬에 눈 덮인 트리, 따뜻한 작은 전구, 차분한 분홍·금빛 장식과 선물 꾸러미를 배치한다. 세계 위치에 고정해 카메라와 두 풍경을 따라 투영한다.
- 얼음 위 캐릭터의 물결 표시를 스키·썰매 자국과 그림자로 바꾸고, 이동에는 작은 기울임을 넣는다. 동작 줄이기 설정에서는 이동 장식 애니메이션을 끈다.
- 행동 아이콘과 문구는 스키·썰매에 맞춰 바뀐다. 탐험 메뉴에서 잠수 버튼·해저 보물 지도를 숨기고 겨울 장비 안내를 보여준다.
- 버튼은 현재 디자인 시스템의 공통 토큰을 사용한다. 데스크톱 하단 조작부는 한 묶음씩 줄바꿈해 글자가 세로로 눌리는 문제를 정리한다.

## 소리

새 소리는 후보 검토 단계다. `docs/audio/WINTER-CANDIDATES.md`에 눈 밟기·스키·썰매의 후보 3개와 원본 링크·라이선스를 기록했다. 이 후보 음원을 다운로드·삽입했다고 보고하지 않는다. 눈 모드에서는 기존 모래 발소리와 개인 뗏목의 노 젓기 소리를 재생하지 않도록 정리했다. 파도 배경음과 명시적 재생·음소거 설정은 유지한다.

## 검증

- `tests/sea-winter.test.mjs`: 기본 장비, 이동속도와 적용 범위, 이전 저장 형식, 근접·눈 한정·중복 획득 조건, 공유 캐릭터 필드 검증. GitHub CI에 추가했다.
- `tests/browser/sea-winter.cjs`: 기본 스키, 수영·잠수 제한, 선물 접근 후 직접 열기, 뗏목→썰매, 속도 비교, 재접속 보관, 일반 날씨 복원, 잠수 중 눈 전환, 잘못된 이동음 방지, 모바일 조작과 가로 넘침.
- 실제 WebGL로 얼음 바다와 트리, 스키, 선물 획득 및 루돌프를 별도 확인한다. ASMR 기능도 별도 회귀 검사한다.

서버가 소유권을 보증하는 유료 아이템이 아니라 기존 로컬 수집 시스템의 계절 장비다. 실제 토스 기기 성능과 다기기 동시 플레이는 기존의 별도 확인 항목으로 남긴다.

검증 결과: 6개 겨울 규칙 검사와 기존 검사 통과. 브라우저에서 선물 직접 획득·일반 썰매 전환·저장 유지·잠수 중 얼음 전환·모바일 조작을 확인했다. 이동속도 실측 비율은 실행별 약 1.35~1.42배였으며, 설정값의 비율은 5.3/3.8이다. 실제 WebGL 눈 바다·트리·스키·선물·루돌프 장면과 ASMR 회귀 흐름을 오류 없이 확인했다. 캡처는 /workspace/outputs/little-sea-winter/에 보관한다.
