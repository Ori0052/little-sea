# 무료 시간·날씨 연결

2026-11-19. 유료 계약·인증키·GPS 권한 없이 동작한다.

## 사용 흐름

설정에서 `직접 선택 / 시간에 맞추기 / 지역 날씨`를 고른다. 기존 사용자 선택은 보존하고 처음 온 사용자는 시간 자동을 기본으로 한다. 지역은 서울·인천·부산·제주·대구·광주·청주·양양이다. 자동 모드에서 수동 날씨 버튼을 누르면 직접 선택으로 전환한다.

한국 표준시와 선택 지역 위경도·계절로 일출·일몰을 근사 계산한다. 일출 전 25분~후 20분, 일몰 전 45분~후 30분 동안 하늘·물색의 낮/노을/밤 비율을 연속 변경한다. 시계 갱신은 1분 간격이며 외부 API가 필요 없다. 천문 관측 시각을 정밀하게 제공하는 기능은 아니다.

지역 날씨는 NOAA/NWS Aviation Weather Center의 한국 공항 METAR 관측을 비·눈·뇌우로 변환한다. 강수 보고가 없으면 시간에 맞춘 풍경을 사용한다. 대표 공항과 관측 시각을 화면에 표시하며, 동네 날씨 또는 기상청 실황이라고 부르지 않는다. 풍속을 태풍으로 해석하지 않는다. 태풍 특보는 연결하지 않았다. 눈은 원본 CSS 입자로 표현하며 새 음원을 생성하지 않는다.

## 데이터 출처와 비용

공식 API: https://aviationweather.gov/data/api/
요청: https://aviationweather.gov/api/data/metar?ids=RKSS,RKSI,RKPK,RKPC,RKTN,RKJJ,RKTU,RKNY&format=json&hours=2
요청 식별: LittleSea/1.0 (https://little-sea.rhfenrdltkfk.chatgpt.site)

공개 API이며 키나 구독을 사용하지 않는다. 현재 안내의 최대 100회/분 제한을 고려해 8개 관측소를 한 번에 조회하고 서버의 고정 캐시 키·30분 캐시·진행 중 요청 합치기를 사용한다. 사용자마다 외부 API를 조회하거나 DB를 기록하지 않는다. 캐시는 Cloudflare 엣지별이며 전 세계 단일 스케줄은 아니다. 장애는 5분간 재시도를 억제한다. 기상 데이터 API 이용료는 0원이나 기존 Worker 요청·캐시 등 호스팅 사용량은 별도다.

Open-Meteo 무료 API는 비상업용 조건 때문에 연결하지 않았다. 기상청 단기예보 API는 무료지만 인증키가 필요하고, 기존 RSS는 중단 안내가 있어 사용하지 않았다. MET Norway는 본인 약관 확인 절차가 있어 이번 연결에서 제외했다.

## 실패·프라이버시·수면

관측 자료가 없거나 90분보다 오래됐거나 미래 시각이 비정상적이면 시간 모드로 대체하고 이를 표시한다. 임의의 비·눈을 만들어 실황이라고 보여주지 않는다. 사용자 GPS·IP를 날씨 제공처에 보내지 않는다. 브라우저는 서버의 집계 자료만 요청하고 선택한 지역은 브라우저에 저장한다. 앱을 숨기거나 수면 모드에 들어가면 새 날씨 요청을 멈춘다. 소리를 자동으로 켜지 않으며 수면 중 선택한 밤/비/모닥불은 자동 날씨가 바꾸지 않는다.

## 보안 및 검증

날씨 경로는 개인정보 없는 집계 자료만 반환하는 GET이다. URL/관측소/좌표 등 쿼리는 받지 않으므로 임의 프록시나 캐시 키 증폭에 사용할 수 없다. 요청 Origin은 기존 웹·토스 허용 목록을 따른다. 기존 상태 변경 API 인증과 요청 제한은 그대로다. 토스 CORS에 날씨 GET만 추가한다.

검증: 관측 분류/오래된 자료/잘못된 관측소/눈비 혼합/주변 뇌우 구분, 지역·계절별 태양 시각, 30개 동시 요청 합치기, 정상/실패 캐시, 허용 Origin과 GET, TypeScript, 웹·토스 빌드. 모바일에서 기존 수동 선택 보존, 시간 모드의 외부 호출 없음, 지역 변경 시 자료 재사용, 비/눈 렌더, 오류 시 시간 대체, 자동 재생 없음, 수면 분리 및 기존 수면 흐름 확인. 실제 WebGL의 연속 태양 색상과 두 시점 렌더링도 확인한다. 개발 환경의 외부 도메인 접근 제한 때문에 공개 서버에서의 실제 관측 응답은 배포 후 별도 확인한다.
