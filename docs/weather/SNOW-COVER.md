# 섬·나무·산과 수면의 쌓인 눈

2026-11-19. 눈 모드에서 얼음 수면의 흰 눈 덮임을 넓히고, 모든 섬 지형·산·바위와 나무 윗면에 설경을 적용한다. 나무줄기와 아래쪽 잎은 원래 색을 일부 유지한다. 텐트·가구의 위쪽 면도 눈을 받으며, 불이 켜진 모닥불 바로 주변의 흰 덮임은 줄인다. 이 변화는 시각적 표현이며 조리·이동·충돌 규칙을 바꾸지 않는다.

지형의 삼각형 방향과 재질 밝기에서 표면별 눈 덮임을 한 번 계산해 정적 GPU 버퍼에 넣는다. 프레임마다 메시를 재생성하거나 별도 모델을 중복 적재하지 않는다. 공통 지형 셰이더의 snow uniform을 바꾸므로 바다 시점과 해변 지도 모두 동일하게 바뀐다. 눈이 아닌 모드에서는 기존 색으로 돌아온다. 기존 야간 자동 날씨도 섬 조명에 반영한다.

검증: 실제 WebGL에서 섬·수목·산의 눈 모드/원상 복구 비교, 두 시점의 셰이더·속성 버퍼 렌더링 및 오류 없음, TypeScript·기존 자동 검사·웹/토스 빌드. 실제 기기 GPU 성능은 별도 확인 항목이다.
