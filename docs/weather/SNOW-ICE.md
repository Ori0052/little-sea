# 눈 결정과 얼어붙은 겨울 바다

2026-11-19. 눈 모드의 작은 점만 보이는 문제를 수정했다. 24개의 육각 눈 결정(12~20px)과 48개의 작은 입자를 서로 다른 위치·속도로 분산한다. 등장 시간은 6초에서 1.2초로 줄이고, 밝은 배경에서도 보이도록 얇은 그림자를 더한다. 동작 줄이기에서는 낙하를 정지하되 눈송이는 화면 전체에 분산해 유지한다.

눈 모드에서 WebGL 바다와 해변 모두 정적인 월드 좌표 얼음판·균열·성에를 표시한다. 카메라 이동 시 얼음이 화면에 달라붙지 않고 지면과 함께 이동한다. 파도 대신 얼음색을 표시하고 해안의 흔들림을 크게 줄인다. 모래 가장자리도 서리색으로 바뀐다. 낮·노을·밤 색상 및 자동 시간 연동을 유지한다. WebGL 미지원 시에도 기존 대체 배경 위로 얼음색과 균열 무늬를 표시한다.

실제 결빙 관측을 제공하는 기능이 아니라 사용자가 요청한 겨울 풍경 연출이다. 눈이 아닌 모드에서는 frozen uniform을 끄며, 이동·뗏목·충돌·보상·음원·수면 규칙은 유지한다. 기존 수영 조작을 얼음 위 걷기로 바꾸거나 뗏목을 잠그지는 않는다.

검증: TypeScript·기존 자동 검사, 실제 WebGL 바다/해변 셰이더 컴파일 및 얼음 모드 렌더링, 모바일 눈 결정 수와 화면 분산·동작 줄이기, 자동 날씨의 눈 관측 연결, 장애 대체, 기존 수면 흐름. 별도 이미지·유료 API·추가 음원은 사용하지 않는다.
