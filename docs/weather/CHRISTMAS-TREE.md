# 눈 모드 크리스마스 트리

2026-11-23. 기존 게임의 부드러운 입체 나무에 맞춰, 화면에 붙여 놓은 평면 SVG 트리를 월드 안의 입체 장식으로 교체한다. 참고 사진의 풍성한 가지·금빛 전구·빨강과 금색 장식·선물 구성을 재해석한 자체 제작 메시이며 사진을 텍스처로 사용하지 않는다.

## 표현과 배치

- 두 섬의 기존 위치를 유지한다. 월드 좌표 (2.7, 25.6), (17.3, 60.8)에 배치하며 두 번째 트리는 86% 크기다.
- 일곱 층의 둥근 가지 묶음과 아래로 처진 가지 끝, 안쪽의 어두운 색으로 깊이를 만든다. 일부 윗면에는 눈을 얹는다.
- 구형 빨강·금색 장식과 아이보리 펜던트, 두께와 경사면이 있는 별, 나무를 감싸는 전선과 작은 금빛 전구를 사용한다.
- 선물상자에는 윗면·옆면과 리본·매듭을 만들고 땅에는 접지 그림자를 둔다.
- 전구는 일정하게 은은히 빛난다. 빠른 점멸이나 별도 전체 화면 빛 효과를 추가하지 않는다. 밤에는 기존 환경 조명을 따르되 전구의 따뜻한 색은 유지한다.

## 렌더링

기존 섬 메시와 같은 WebGL 컨텍스트·카메라·깊이 버퍼를 사용한다. 달빛 수평선에서는 높이와 원근이 보이고, 파도 해변에서는 위에서 본 수관과 장식이 보인다. 화면에 고정된 트리를 별도로 중복 표시하지 않는다. 불멍의 근접 화면은 기존 배경 생략 규칙을 따른다.

정적 메시를 처음 필요할 때 한 번 생성해 GPU 버퍼에 올린다. 프레임마다 메시를 만들거나 별도 캔버스를 띄우지 않는다. 두 그루 합산 버퍼는 3MiB 미만으로 제한한다. GPU 컨텍스트 해제·재생성에는 기존 자원 정리 경로를 사용한다.

WebGL을 사용할 수 없으면 명암과 곡선 가지·구형 장식으로 개선한 SVG 대체 그림을 표시한다. 눈 모드를 끄면 두 렌더링 경로 모두 계절 트리를 표시하지 않는다. 이동 규칙·아이템 획득·음원은 이번 변경 범위에 포함하지 않는다.

## 검증

- `tests/christmas-tree.test.mjs`: 유한한 정점·색상과 재질 범위, GPU 포맷·메모리 예산, 두 섬의 접지와 세 축 부피, 앞뒤 전구, 결정적인 배치.
- `tests/browser/christmas-tree.cjs`: 실제 WebGL의 눈·낮·밤, 시점 회전과 두 풍경, 중복 SVG 숨김, 일반 날씨 복원, 모바일 대체 그림과 가로 넘침.
- 기존 겨울 이동·선물·썰매 회귀 검사와 웹·토스 빌드를 실행한다. 실제 기기의 프레임률은 별도 확인 대상이다.
