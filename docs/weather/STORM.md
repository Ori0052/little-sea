# 천둥 날씨와 뗏목 파도 연출

2026-11-18 변경. 천둥 모드에서 짙은 먹구름, 남색 바다, 넓은 너울과 밝은 포말을 표시한다. 일반 비/낮/노을/밤은 기존 표현을 유지한다. 바다와 해변 WebGL 모두 별도 tempest uniform을 사용한다.

뗏목 탑승 중 SVG만 2.8초 주기로 -8~10도 기울고 위아래로 이동한다. 캐릭터와 뗏목은 함께 움직이며 기존 좌표, 이동 방향, 충돌과 터치 판정, 카메라는 변경하지 않는다. 실제 전복이나 보상 손실은 없다.

천둥 재생 이벤트에 맞춰 1.8초 동안 두 번 밝아지는 번개를 표시한다. 서로 다른 천둥 이벤트는 최소 4초 간격으로 제한하며 기존 45~75초 천둥 스케줄은 유지한다. 소리를 끈 경우에도 기존 시각 이벤트를 사용할 수 있다. 번개 설정을 끄거나 동작 줄이기가 켜지면 번개를 표시하지 않는다. 동작 줄이기는 뗏목/구름 애니메이션과 파도 시간도 정지한다. 수면 모드는 기존 조용한 밤/비를 유지하고 천둥 연출을 실행하지 않는다.

검증: TypeScript, 기존 51개 회귀 테스트 및 토스 9개 플랫폼 테스트; 실제 WebGL 바다/해변 셰이더 컴파일·렌더링·모드 변경; 실제 장착 뗏목의 이동 중 롤링, 동작 줄이기, 천둥 해제; 실제 천둥 음원·번개 동기화, 비 음원 미실행, 번개 끄기. 실제 기기 프레임 속도와 모션 선호도는 추가 확인이 필요하다.

## 2026-11-18 추가: 번개 12종·비 동반·입체 구름

천둥은 이제 비와 빗소리를 동반한다. 기존 일반 비의 선택형 천둥도 유지한다. 빗소리는 파도와 함께 서서히 섞이며, 음소거/백그라운드/수면 정책은 기존과 같다.

12개의 원본 절차형 번개 실루엣을 고정 시드로 생성한다. 밝은 청백색 중심, 가는 가지, 더 가는 잔가지를 별도로 그린다. 매 발생마다 직전 형태를 제외한 11종 중 하나를 골라 위치(가로 24~76%), 크기(0.65~1.2), 기울기(-23~23도), 좌우 반전을 변경한다. 형태와 위치는 해당 번개 동안 고정된다. 이벤트당 두 번의 완만한 점등과 기존 최소 간격은 유지한다.

마스킹으로 번개 일부가 구름에 가려지고, 발생 지점 근처에 푸른 국소 광량을 더한다. WebGL 하늘은 여러 크기의 노이즈와 방향성 명암으로 구름 덩어리·그림자·밝은 가장자리를 표현한다. 새 이미지나 외부 영상은 사용하지 않는다. 저사양 장치는 기존 대체 배경을 사용한다.

추가 검증: 12종의 고유 형태와 연속 중복 방지 및 위치 범위를 검사했다. 브라우저에서 천둥과 실제 빗소리·빗방울 동시 재생, 번개 끄기, 동작 줄이기를 확인했다. 모바일 SVG 12회 이벤트의 형태 변화와 중복 차단, 실제 WebGL 바다·해변 셰이더 컴파일/렌더링도 확인했다. 자동 회귀 검사는 웹 52개 + 네이티브 9개다. 실사 사진과 동일한 구름을 보장하는 것은 아니며 실제 모바일 GPU 성능은 별도 확인 항목이다.
