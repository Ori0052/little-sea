# 링크 공유 미리보기

Threads 등 링크 수집기가 JavaScript 실행 없이 읽을 수 있도록 루트 서버 HTML에 Open Graph 제목·설명·절대 이미지 URL을 제공한다. 현재 승인된 600×600 작은 섬·파도 로고를 사용하며 별도 디자인을 새로 만들지 않는다. Twitter summary 카드도 제공한다.

정식 주소: https://little-sea.rhfenrdltkfk.chatgpt.site/
이미지: /brand/app-icon-600.png?v=lavender-1

플랫폼이 이미 수집한 링크 정보는 자체 캐시에 남을 수 있다. 새 게시물로 링크를 확인하고, 이전 게시물의 미리보기가 즉시 갱신된다고 보장하지 않는다. 이미지 URL을 바꾸는 향후 작업에서는 Open Graph와 Twitter 항목을 함께 갱신한다.
