# 종이배 편지 30종 일괄 적용

사용자가 승인한 생성 편지지 30장(1:1)을 적용한다. 원본 PNG는 검토 파일에 보존하고 웹에는 구도·해상도를 유지한 WebP를 넣었다(총 약5MB). 처음 30통은 이미 가진 도안을 제외해 순서대로 발견한다. 이후에는 최근30통 보관 정책 안에서 순환한다.

발견: 게임 중 종이배를 직접 선택해 다가갔을 때만 하루 한 통, 한국 날짜 기준으로 획득한다. 조개, 홈의 빈 영역, 잠수/수면/휴식/메뉴 상태에서는 발견을 열지 않는다. 홈의 상시 편지 버튼은 삭제했다. 첫 안내에서 발견 방법만 소개한다.

열람: 봉투 → 편지 펼치기 → 글과 그림이 합쳐진 정사각형 편지. 움직임 줄이기에서는 펼침 애니메이션을 생략한다. 읽는 동안 이동을 멈추며, 닫아도 같은 날짜에는 다시 발견하지 않는다. 메뉴 → 내 정보 → 편지함에서 다시 읽는다.

저장: 발견한 날짜·도안 ID·제목·글을 브라우저 저장소에 함께 기록한다. 예전 7종 편지는 원래 글을 유지한다. 이 기록은 이미지 파일 자체가 아니라 완성 편지를 재현하는 데이터다. 별도 ‘글이 포함된 편지 이미지 저장’을 누르면 실제 배경과 글을 합성한1254×1254 PNG를 내려받는다. 앱 안의 미리보기와 다운로드는 같은 합성 결과를 사용한다. 토스에서는 기존 saveImage 어댑터를 사용하며 실제 기기의 저장 승인/지원 여부에 영향을 받는다.

기기 저장소를 지우거나 다른 브라우저를 쓰면 기록은 공유되지 않는다. 저장 실패 시 이번 방문 동안만 보관한다고 표시한다. 하루 제한은 기존 로컬 수집 모델이며 서버 계정 기반의 기기 간 제한이 아니다.

문구는 휴식·자기 돌봄을 위한 창작 문장으로, 불면증 치료나 특정 생물의 의학적 효능을 주장하지 않는다.

검증: 웹51개 + 네이티브9개 자동 검사 통과. 모바일에서 홈 편지 버튼/빈 클릭 영역 제거, 종이배 선택·실제 접근·발견, 같은 날 재발견 차단, 내 정보 편지함 열람 확인. 실제 PNG 다운로드·1254×1254 치수·Canvas에 제목과 글 렌더링 확인. 내려받은 PNG를 직접 검토하고 단어 단위 줄바꿈을 적용했다. 수면 모드 소리·타이머·화면 어둡게 회귀 검사 통과. 실제 토스 기기의 파일 저장 및 잠금 중 소리는 별도 기기 검증 대상이다.
