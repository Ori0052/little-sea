# 편지 날짜·타이포그래피 정렬

순서: 날짜 → ‘작은 바다에서, 당신에게’ → 제목 → 본문 → 서명.

1254×1254 캔버스에서 모든 텍스트를 x=627 중앙축에 맞춘다. 날짜27px, 인사말30px, 제목58px, 본문48px, 서명28px. 본문 기준선 간격82px(약1.7배), 자간0px, 기본 커닝 사용. 글리프의 실제 상하 경계로 각 영역의 높이를 계산하고 날짜/인사말/제목/본문 간 간격을 따로 둔다. 제목을 가로로 압축하지 않는다. 단어 단위 줄바꿈 후 줄별 길이를 균형 있게 맞춰 마지막 한 단어만 남는 현상을 줄인다.

미리보기와 저장은 같은 합성 PNG를 사용한다. 30종 모두 실제 브라우저에서 생성하여 날짜 우선, 헤더 겹침 없음, 중앙축 동일, 자간0px, 본문 기준선 간격82px, 가로/세로 글 영역 내 배치를 확인했다. 서로 다른 배경의 샘플도 눈으로 검토했다.
