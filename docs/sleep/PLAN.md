# 수면 중심 이야기와 출시 1차 범위

목적: 잠들고 싶은데 생각이 많고 긴장이 남은 밤, 소리를 직접 선택해 잠들 준비를 돕는다. 불면증 치료·수면 시간 측정·수면 유도 효능은 주장하지 않는다.

시작 화면: 종이배의 초대 → 오늘 밤 쉬기 / 가볍게 바다 둘러보기. 기존 이용자도 새 안내를 한 번 볼 수 있도록 안내 버전을 변경하고 조작 도움말을 유지한다. 재방문에도 홈에서 수면 화면을 열 수 있다.
수면 화면: 밤 파도·빗소리·모닥불, 15/30/60분/계속 듣기, 음량, 직접 소리 시작/중지, 화면 어둡게 하기. 타이머 마지막 30초에 볼륨을 줄이고 끝나면 소리를 멈춘다. 종료 알림·효과음은 없다. 일반 휴식으로 돌아오면 기존 풍경과 음량을 복원하며 사용자 동의 없이 소리를 다시 켜지 않는다.
수면 중: 게임 조작·연결·입질·보상·발걸음·천둥·번개를 멈춘다. 기존 그래픽·탐험·수집은 바다 둘러보기에서 유지한다. 소리를 켜지 않고도 화면에 들어갈 수 있다.
재미: 오늘의 종이배 편지. 한국 날짜를 기준으로 같은 날 같은 편지, 원하는 편지만 기기에 최대30통 보관. 출석 연속 기록·꽝·과제·수면 중 획득음 없이 진행한다.
브랜딩: 기존 섬/파도 로고 및 이름 유지. 도입과 수면 UI에 짙은 남색, 라벤더, 달빛색 사용. 기존 낮 UI는 보존한다.
제약: 실제 기기에서 화면 잠금·앱 전환 오디오 유지 여부는 별도 검증 대상이다. 브라우저가 정지된 동안 정확한 종료시각을 보장하지 않으며 복귀 시 절대 종료시각으로 즉시 정리한다. 백그라운드 재생을 지원한다고 광고하지 않는다.
