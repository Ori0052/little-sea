# 종이배 편지 — 다음 편지 안내

문제: 하루 한 통인 편지를 읽은 뒤 다음 편지를 다른 종이배에서 찾거나 별도 행동으로 얻는다고 오해할 수 있었다.

변경:
- 오늘의 날짜와 하루 한 통이라는 기준을 표시한다.
- 본문 아래에 ‘오늘의 편지는 여기까지예요. 다음 편지는 내일 도착해요.’와 한국 시간 자정(밤12시) 교체 안내를 상시 표시한다.
- 같은 ‘오늘의 종이배 편지’에서 읽으면 되며 다른 종이배를 찾을 필요가 없다고 알린다.
- ‘간직한 편지 다시 읽기 · N통’으로 보관함 이름을 바꾸고 비어 있을 때 저장 방법을 안내한다.
- 자정에 한 번 예약 실행하며 창 포커스/다시 보임에도 날짜를 확인한다. 새 편지로 바뀌어도 기존 저장 편지는 유지한다. 추가 통신/DB 호출은 없다.
- 날짜가 준비되기 전 편지 진입 버튼을 비활성화해 초기 로딩 중 클릭 누락을 막는다.

검증: 한국 자정 경계 및 연말 경계 단위 검사, 모바일 실제 화면에서 안내·비어있는 보관함·저장·자정 자동 교체·기존 편지 다시 읽기·여러 날 후 복귀·가로 넘침 없음 확인. 기존 저장 데이터와 기기 내 최근30통 정책 유지.
