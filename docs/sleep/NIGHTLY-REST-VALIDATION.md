# 매일 밤 휴식 개편 — 로컬 검증 기록

공개 배포와 GitHub CI의 최종 식별자는 제출 폴더의 `build-info.json`에 기록한다. 아래는 소스 구현의 로컬 검증 범위다.

- 공통 자동 회귀: 82개. 수면일지·진입 복원·입력 파싱·7일 요약·자정 시각 폭·토스/웹 정책 검사 10개를 추가했다.
- 공통 및 토스 TypeScript 검사를 통과했다.
- `sea-entry.cjs`: 320×568 / 390×844 / 1280×800px, 첫 방문 게임·온보딩·짧은 두 선택·재방문 생략·게임/휴식 전환·직접 휴식 API 격리. 재생·어둡게 버튼이 첫 화면에서 하단바에 가리지 않는다.
- `sea-rest-journal.cjs`: 저장된 소리·음량·타이머·풍경, 자동 재생 없음, 마지막 화면 복원과 해제, 수면일지 생성·재수정·개별/전체 삭제, 빈 날을 제외한 평균, 미확인 종료 시각, 편지함 위 편지 읽기, 저장 차단 복구. 네이티브 호스트·화면 숨김은 모의 환경이다. 토스 숨김 정지/복귀, 웹 휴식 지속, 숨김 중 타이머 만료 후 재개 금지, 미디어 메타데이터 정리·만료 후 OS 재생 제어 차단을 확인했다.
- `sea-sleep-flow.cjs`: 실제 MP3 밤바다·불·비가 재생되고 부드럽게 전환된다. 마지막 30초 페이드와 절대시간 만료 후 모든 음원이 멈춘다. 휴식 중 게임 접속자 호출·보상·효과음을 발생시키지 않는다.
- `sea-navigation.cjs`: 게임 메뉴·세부 탐색·의상 저장·편지 접기·포커스 복원·설정·섬 활동, 44px 이상 탭 조작 영역, 모바일 안전 영역, 가로 넘침 없음.
- `sea-winter.cjs`: 기본 스키·잠수 금지·크리스마스 장식·루돌프 획득 단발성·썰매 전환·속도 차이·재접속 저장·일반 날씨에서 뗏목 복귀·모바일 경로와 이동 소리 회귀.
- 위 브라우저 흐름에서 JavaScript 예외가 없었다. 390px 휴식과 수면일지 요약 화면을 직접 시각 검토했다.

실기기 검증을 했다는 뜻은 아니다. iOS/Android의 잠금·장시간 절전·오디오 끼어듦, 토스 앱 검수 및 수면 측정 센서 연동은 완료 범위에 포함하지 않는다. 토스 콘솔에는 업로드하지 않는다.
