# 잠들기 전 찾아오는 작은 바다 — 실행 기획서

## 목적과 재방문 이유

사용자가 매일 밤 익숙한 소리로 쉬고, 원할 때 아침의 기분을 돌아보는 공간을 만든다. 큰 유리 파도·종이배 이미지와 기존 게임의 정체성을 유지한다. 출석 과제·연속 기록·소리를 오래 들으면 받는 보상을 만들지 않는다.

재방문 가치는 지난 소리·음량·타이머·풍경을 기억하는 편리함, 날짜마다 바뀌는 안심 문장, 사용자가 직접 남긴 아침 기록의 흐름이다. 불면증 치료나 자동 수면 측정을 주장하지 않는다. 종이배 편지는 기존 게임에서 한국 날짜당 한 통을 발견하며, 휴식에서는 이미 발견한 편지만 다시 읽는다.

## 진입과 화면

| 상황 | 동작 |
| --- | --- |
| 첫 방문 기본 주소 | 게임 위 기존 온보딩. ‘게임 플레이하기 / 오늘은 쉬기’ 두 버튼. 소리 자동 재생 없음 |
| 안내를 마친 재방문 | 마지막 모드 복원. ‘다음에도 마지막 화면으로 시작’ 설정으로 해제 가능 |
| 명시적인 #game / #asmr | 링크가 기억된 모드보다 우선. 직접 휴식 진입은 게임이나 접속자 API를 실행하지 않음 |
| 오늘은 쉬기 | 큰 바다 이미지와 한 플레이어. 소리 선택, 음량, 재생·멈춤, 타이머, 화면 어둡게 |
| 아침 | 선택형 ‘어젯밤은 어땠나요?’ 진입. 밤에는 기록 작성 요구 없이 안심 문장만 노출 |
| 어둡게 | 검은 화면과 화면 밝히기만 노출. 배경은 inert·aria-hidden. Escape와 토스 뒤로가기로 복귀 |

소리·타이머·풍경은 뒤로가기형 세부 메뉴로 연다. 설정에는 마지막 화면 복원, 편지함, 쉼 기록, 음원 출처를 둔다. 편지를 접으면 편지함이 남는다. 하단 모드는 계속 게임 / 오늘은 쉬기 두 개를 유지한다. 320×568, 390×844, 1280×800px에서 주요 버튼이 하단바 위에 들어오도록 이미지 영역에 남은 높이를 배정한다. 짧은 화면은 그림 크기를 줄이며, 오류나 확대 글씨 등 넘치는 내용은 스크롤할 수 있다.

## 소리와 타이머

- 기존 최적화 파도·밤바다·비·모닥불 파일을 사용하고 출처를 유지한다. 소리·음량·타이머·풍경을 저장하며 진입·새로고침으로 자동 재생하지 않는다.
- 15 / 30 / 60분 / 계속 듣기. 실제 재생 성공 후 절대 종료시각을 잡는다. 재생 중 시간을 바꾸면 그 순간부터 다시 센다.
- 마지막 30초에 음량을 점차 줄이고 종료 후 알림음 없이 멈춘다. 다시 듣기는 사용자의 명시적인 재생 버튼으로 시작한다.
- 복귀·pageshow·오디오 timeupdate에서도 종료시각을 확인한다. 시간이 지난 타이머를 화면 복귀나 시스템 재생 제어가 자동으로 다시 시작하지 않게 한다.
- 지원 브라우저에서는 Media Session 제목·재생·일시정지 제어를 제공하고, 게임으로 나가면 정리한다. 이것이 운영체제의 백그라운드 권한을 부여하지는 않는다.

## 선택형 아침 기록과 요약

일어난 날짜(한국 시간), 잠자리에 든 시각, 일어난 시각, 아침 기분(개운함·보통·피곤함)을 기록한다. 잠들기까지 걸린 시간과 깬 횟수는 선택 입력이다. 같은 날짜를 다시 저장하면 수정하며 개별 삭제가 가능하다. 취침 시각이 기상 시각보다 늦으면 전날 밤으로 계산하고 낮잠도 허용한다. 미래·잘못된 날짜, 같은 시각, 잘못된 선택값과 범위를 거른다.

최근 7개 기록이 아닌 **최근 7일의 실제 기록**을 요약한다. 빠진 날은 평균에 넣지 않는다. 평균은 ‘침대에 머문 시간’으로 표시하고 실제 수면 시간과 구별한다. 3일 이상 기록되면 자정을 가로지르는 취침 시각의 폭을 계산한다. 수면 점수·수면 단계·잠든 시각·개선 효과를 추정하거나 만들어내지 않는다.

아침의 ‘나의 흐름’에서 CDC·NIH의 수면 안내를 링크한다. 충분한 수면과 기분·집중, 규칙적인 취침·기상 습관을 다루며, 취침 직전에는 건강 학습이나 과제를 요구하지 않는다.

## 저장과 삭제

- 설정 `little-sea-rest-preferences-v1`, 진입 설정 `little-sea-entry-v1`, 기존 공통 음량 설정은 브라우저에 보관한다. 토스에서는 알려진 설정 키만 기존 네이티브 저장 복원에 포함한다.
- 수면일지 `little-sea-sleep-diary-v1` 최대 90개, 재생 기록 `little-sea-rest-sessions-v1` 최대 60개. 브라우저 로컬에만 두며 서버 API·AI·토스 저장 백업에 넣지 않는다. 다른 기기에 동기화하지 않는다.
- 재생 기록은 앱의 재생 세션이다. 직접 기록한 수면일지와 별개이며, 잠을 잤다고 판단하지 않는다. 예기치 않은 종료는 마지막 확인 시각만 남기고 종료 시각을 채워 넣지 않는다.
- 전체 삭제는 화면 내 확인 후 소리를 멈추고 두 기록만 지운다. 편지·수집품·설정은 보존한다. 저장을 쓸 수 없으면 경고와 함께 현재 화면에서 사용할 수 있다.

## 백그라운드와 검증 경계

웹은 휴식 오디오를 화면 숨김만으로 멈추지 않는다. 기존 웹 게임의 숨김 정책은 보존한다. 실제 iOS/Android 브라우저의 화면 잠금·절전 정책은 별도로 확인해야 하며, OS가 JavaScript를 정지하는 동안 정확한 페이드나 종료를 보장하지 않는다.

토스는 앱 숨김 시 오디오 정지와 복귀 시 유효한 타이머에 한한 재개를 유지한다. 공식 담당자는 HTMLAudioElement로 잠금 재생은 가능하지만 지속 백그라운드 재생이 비게임 앱에도 검수 반려 사유가 될 수 있다고 안내했다. 따라서 이번 빌드에서 이 정책을 우회하지 않는다. 토스에서 밤새 화면을 잠근 채 듣는 기능은 지원 완료로 표시하지 않는다.
