# 수면 이야기 구현 결과

## 반영 범위
- 새 안내 버전(v2): 종이배의 초대와 밤의 바다 이야기. 사용자가 수면 준비와 탐험을 직접 선택한다. 기존 안내를 본 이용자에게도 새 이야기가 한 번 표시된다.
- 기존 도움말·바다·로고·탐험·수집 기능 유지. 홈의 오늘 밤 쉬기와 종이배 편지 진입 추가.
- 수면 전용 화면: 밤 파도, 비, 모닥불, 음량, 15/30/60분 또는 계속 듣기, 화면 어둡게 하기.
- 소리 동의 없이 재생하지 않는다. 실제 재생이 시작되면 타이머가 시작하며 마지막 30초에 음량 감소. 종료음과 보상은 없다. 재생 오류는 화면에 표시한다.
- 수면 화면에서는 정상 게임 화면을 inert 및 숨김 처리하고 조작·온라인 연결·게임 효과음·번개를 중지한다. 종료 시 풍경·음량·화면 모드를 복원하며 소리는 자동 재개하지 않는다.
- 종이배 편지 7종, 한국 날짜 기준 하루 한 통, 기기 내 최대30통 간직하기. 출석·재촉·실패·획득음 없음.

## 검증
- TypeScript 통과, 웹 검사47개 + 네이티브 검사9개 = 56개 통과.
- 모바일 실제 오디오: 처음 무음 → 밤 파도 → 모닥불 → 비 전환 확인.
- 절대 시간 이동으로 마지막 15초 페이드 및 타이머 종료/전체 정지 확인.
- 수면 중 게임 효과음과 접속 통신이 발생하지 않음 확인.
- 화면 어둡게/밝히기, 수면 종료, 편지 간직하기 및 중복 방지, 가로 넘침 없음 확인.
- 기존 휴식/재방문/도움말/소리 동의 회귀 브라우저 검사 통과.
- 모바일 캡처로 시작 안내와 수면 UI의 대비/정렬 검토.

## 남은 검증
- 실제 토스 기기의 잠금/앱 전환/절전 재생은 검증 전이며 지원한다고 주장하지 않는다.
- 기기가 브라우저 타이머를 정지시키면 정각 종료를 보장하지 않는다. 다시 실행되면 절대 마감 시각에 따라 종료한다.
- 불면증 치료 효과나 잠들기까지의 시간 개선은 측정/검증하지 않았다.
