# 공통 버튼 색상

2026-11-23. 첫 선택 화면과 ASMR의 보라색, 기존 게임의 파란색을 하나의 브랜드 라벤더로 통일했다.

공통 변수는 sea-design-system.css의 --sea-brand-*에 정의하며, 게임 --sea-action과 ASMR --asmr-accent가 같은 값을 참조한다.

- 기본/선택: #8066AA, 글자 #FFFFFF.
- 마우스 올림: #705692, 누르는 중: #62477F.
- 밝은 보조 버튼: 연한 라벤더, 밤 화면: 어두운 보라색 계열. 보조/윤곽 버튼의 역할 차이는 유지한다.
- 기본색과 흰 글자의 대비는 약 4.77:1이다. 밤/천둥에서도 주요 버튼 기본색과 흰 글자를 유지하고 포커스 테두리는 밝게 표시한다.

적용: 첫 화면의 주요 실행 버튼, ASMR의 수면 진입/재생, 수면의 재생·선택 소리·타이머, 게임의 ASMR/수면 진입·날씨/풍경 선택 및 기존 공통 주요 실행 버튼. 색이 별도로 지정돼 있던 게임 첫 진입 링크와 천둥 풍경 선택도 공통 변수로 교체했다. 기능·배치·풍경은 바꾸지 않았다.

검증: 브라우저에서 첫 화면·ASMR·수면·게임의 낮/밤/천둥 기본색, 글자색, 그라데이션 없음, 올림/눌림 상태를 비교했다. 기존 ASMR 진입·편지·재생·타이머·게임 복귀 흐름도 확인했다. 웹·토스 빌드 및 기존 CI 검사를 수행한다.
