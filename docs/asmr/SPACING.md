# ASMR 여백 및 버튼 배치 정리

2026-11-23. 휴식·수면·진입 화면의 빽빽한 배치를 정리했다.

- 공통 간격: 8/12/16/24/32/48px, 모바일 좌우 20~24px·데스크톱 40px.
- 제목과 설명, 풍경, 소리 카드 사이에 독립적인 여백을 둔다. 소리 카드는 내부 20~24px 여백을 사용한다.
- 휴식 메뉴는 서로 붙은 구분선 대신 12px 간격의 버튼으로 나누고, 실행 버튼과 게임 이동 링크 사이도 넓힌다.
- 수면 조작부는 소리 선택/음량, 타이머, 실행/어둡게의 세 묶음으로 나눈다. 묶음 사이 32~40px, 실행 버튼 사이 16px를 둔다.
- 소리 선택은 아이콘과 이름을 세로로 배치한다. 400px 미만 화면의 타이머는 2×2로 배치해 글자와 버튼 여백을 확보한다.
- 짧은 화면에서 간격을 다시 줄이던 규칙을 제거한다. 화면 높이가 부족하면 자연스럽게 스크롤하며 모든 조작을 사용할 수 있다. 네이티브 안전 영역은 유지한다.

중복된 ASMR CSS 재정의들을 하나의 규칙으로 정리했다. 이미지·음원·타이머 계산·게임 규칙은 변경하지 않는다.

검증: TypeScript, 320×640·390×844·1280×900의 가로 넘침 없음 및 버튼 접근, 타이머·어둡게·복귀, 기존 ASMR의 편지/저장 데이터 보존/게임 이동, 기존 수면의 실제 음원과 감쇠·종료 흐름. 웹·토스 빌드와 기존 CI 검사도 수행한다. 실제 기기의 폰트 설정·안전 영역 확인은 별도 항목이다.
