# ASMR 휴식·수면 경험 — 구현 및 연결

2026-11-20. 승인된 반투명 파도 시안을 별도 ASMR 화면으로 구현했다. 기존 게임의 지형·캐릭터·날씨·탐험 규칙은 유지한다.

## 진입과 이동

첫 화면에서 `소리 들으며 쉬기`와 `바다 둘러보기`를 선택한다. `/#asmr`은 ASMR로, `/#game`은 기존 게임으로 바로 들어간다. 브라우저 뒤로가기/앞으로가기로 선택을 되돌릴 수 있다. 게임의 첫 화면과 설정에서도 ASMR로 이동한다. 기존 시작 안내는 게임을 골랐을 때만 표시한다.

ASMR과 게임을 동시에 마운트하지 않는다. 게임 모듈은 지연 로딩해 첫 선택/ASMR에서 지형 메시 생성을 실행하지 않는다. 따라서 ASMR은 접속·이동·날씨 조회·게임 효과음·보상 통신을 실행하지 않는다. 게임을 나가면 기존 정리 절차로 연결과 음원을 종료하며, 돌아갈 때 현재 게임 세션/위치는 다시 연결된다. 소집품·옷·뗏목·편지는 기존 저장 키를 그대로 사용한다.

## 시각적 구현

사용자가 승인한 시안을 기준으로 청록빛 휴식과 남색 수면 장면을 새로 생성했다. 동일한 달·네 척의 종이배·모자 쓴 사람·파도 구도를 유지하고 조명을 바꾼 두 WebP를 사용한다. 원본 SHA와 배포본 SHA는 `public/asmr/manifest.json`에 기록한다. 화면 UI는 이미지가 아니라 실제 텍스트·버튼·입력 요소다.

현재 장면은 사전 렌더링 이미지와 느린 3px 부유 모션이다. 개별 파도나 캐릭터가 움직이는 3D 장면은 아니다. 두 이미지 합계 약 75KB이며 외부 이미지 서버나 새로운 3D 라이브러리를 요구하지 않는다. 동작 줄이기에서는 부유/전환을 끈다. 헤더·버튼·슬라이더·모달은 ASMR 전용 CSS로 기존 게임과 구분한다.

## 작동하는 기능

- 휴식: 파도/비/모닥불 선택, 직접 재생·정지, 음량, 밝은 바다/달빛 풍경, 기존 편지함, 게임으로 이동.
- 편지함: 게임에서 발견한 최근 30통을 같은 키로 읽고 기존 종이편지·PNG 저장 흐름을 재사용한다. ASMR에서 새 편지를 자동 지급하지 않는다.
- 수면: 같은 장면의 낮은 조명, 기존 밤 파도/비/모닥불, 15/30/60분·계속 듣기, 마지막 30초 감쇠와 종료, 화면 어둡게/밝히기.
- 최초 진입과 소리 변경은 음소거를 해제하지 않는다. 휴식에서 직접 켠 소리는 수면에 이어지고, 수면에서 휴식으로 돌아가도 선택한 소리를 유지한다. 모드를 떠나면 ASMR 음원을 정리한다.
- 토스: 휴대폰 뒤로가기는 열린 모달을 먼저 닫고, 어두운 화면→수면→ASMR→처음 선택 순서로 한 단계씩 돌아간다. 편지·새 시작 안내 키를 네이티브 백업 대상에 포함한다. 새 권한은 요구하지 않는다.

## 검증

기존 자동 회귀 검사와 TypeScript·웹·토스 빌드를 수행한다. 브라우저에서 선택 화면·해시 진입·기존 게임 복귀, 데이터 보존, 편지함 읽기, 명시적 소리 재생, ASMR에서 게임 API 호출 없음, 수면 타이머·어두운 화면·복귀, 360px 모바일/1280px 데스크톱·가로 넘침 없음·동작 줄이기·이미지 디코딩을 확인한다. 기존 게임의 시작 안내·휴식·수면 실제 음원/타이머 흐름도 회귀 확인한다. 실제 토스 기기의 잠금/백그라운드 소리 정책과 화면 성능은 추가 확인 항목이다.
