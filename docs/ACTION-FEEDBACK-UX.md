# 행동 버튼과 상태 안내 정리

버튼은 누르면 실행되는 행동에 사용하고, 진행 중 상태는 짧은 텍스트로 표시한다. 취소·종료·정박·내리기는 실제 조작이므로 유지한다.

| 상황 | 변경 |
| --- | --- |
| 배로 다가가는 중 | 접근 버튼을 숨기고 남은 거리만 표시. 탑승 가능한 거리에서 함께 타기 표시 |
| 배가 만석·항해·탑승 확인 중 | 비활성 버튼 대신 상태 문구 |
| 목적지 이동 | 큰 방향 카드·별도 취소 버튼을 없애고 거리 문구와 기존 하단바 멈추기로 통합 |
| 텐트·섬 발견 지점 접근 | 이동 중 같은 접근 버튼 숨김. 도착하면 입장·발견 행동 표시 |
| 고구마·생선 조리 | 조리 중은 음식 이름·진행 상태 표시. 시작·먹기·탄 음식 정리만 버튼 |
| 완료한 탐험 기록 | 비활성 완료 버튼 대신 기록 상태 문구 |
| 모달·탑승 중 | 해당 상황에 맞지 않는 이동 안내·조작 팁 숨김 |

낚시 대기 버튼은 길게 눌러 종료하는 기능이 있어 유지한다. 수집품의 월드 그래픽과 보상 판정은 변경하지 않는다.

개발 기준: JourneyKind로 이동 목적을 명시하고 표시 문구로 상태를 판별하지 않는다. boatAction으로 탑승 상태를 결정하고 CookingAction으로 두 음식의 공통 표시 규칙을 공유한다. 회귀 테스트는 실제 컴포넌트를 렌더링하여 접근·탑승·만석·항해·조리 상태에서 가능한 행동을 확인한다.
