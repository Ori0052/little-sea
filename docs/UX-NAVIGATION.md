# 하단 탐색 UI 개편

2026-11-23. 토스 참고 화면의 둥근 탭바와 ‘뒤로가기 + 해당 영역의 메뉴’ 구조를 바다 경험에 적용한다. 이번 단계는 탐색 구조와 공통 하단바를 정리하며, 게임 그래픽이나 수집 기록 형식은 바꾸지 않는다.

## 정보 구조

| 기본 탭 | 안에서 보이는 메뉴 |
| --- | --- |
| 바다 | 현재 위치의 게임 풍경 |
| 탐험 | 지도 / 섬 / 장비 |
| 수집함 | 수집품 / 보물 / 부적 |
| 내 정보 | 프로필 / 옷·장비 / 편지함 |
| 전체 | 주요 영역 바로가기, ASMR 휴식, 바다 설정, 이용 안내 |

세부 화면의 하단바는 왼쪽 뒤로가기와 세 개의 영역 메뉴로 제한한다. 뒤로가기·닫기·Escape·토스의 시스템 뒤로가기는 화면을 닫고 기존 캐릭터 위치로 돌아간다. 탐색을 위해 해변으로 이동시키지 않는다. 전체 메뉴의 바로가기도 같은 세부 화면을 열며 별도의 중복 화면을 만들지 않는다.

편지함에서 편지를 펼치면 그 위에 편지 한 장만 연다. 편지를 접으면 원래 편지함이 남는다. 옷 변경·편지·장비 소유 기록은 기존 저장 형식을 그대로 사용한다.

## 행동과 탐색의 구분

기존 하단바의 쉬기·잠수·노 젓기·해변으로·음소거는 목적지 탭에서 제외한다. 바다에서는 현재 가능한 행동을 작은 조작부로 하단바 위에 표시하고, 해변 복귀는 해변에서 떨어져 있을 때 표시한다. 소리는 명시적으로 켜야 시작한다.

날씨·음량·도움말 등을 한꺼번에 노출하던 데스크톱 하단 설정부는 전체 → 바다 설정으로 옮긴다. 설정도 날씨 / 소리 / 화면으로 나눠 한 번에 한 묶음만 보여준다.

섬의 활동 바는 뒤로가기와 불멍·굽기·낚시로 줄인다. 장작·오로라는 모닥불 조작 메뉴에서 이용한다. 섬의 뒤로가기는 전체 메뉴를 열어 탐험·내 정보·설정 등에 접근하게 하며 캐릭터를 이동시키지 않는다.

ASMR 휴식에도 같은 하단바 컴포넌트를 사용한다. 휴식 / 소리 / 편지함 / 풍경 / 전체로 이동하고 세부 화면에는 뒤로가기를 둔다. 수면 화면과 어둡게 한 화면에는 탐색 바를 표시하지 않는다.

## 공통 디자인

- `SeaTabBar`가 기본형·뒤로가기형을 함께 제공한다. `SeaNavDialog`가 제목·닫기·내용 스크롤·하단바와 포커스 복귀를 관리한다.
- 하단바는 밝은 흰색 또는 어두운 남색의 단일 면이다. 선택한 목적지는 진한 아이콘·굵은 글자로 표시한다. 라벤더 주요 행동 버튼과 탐색 선택 상태를 구분한다.
- 기본 높이 76px, 아이콘 24px, 글자 12px, 뒤로가기 원 48px. 세로 공간이 작은 화면에서는 바 높이 64px로 조정한다. 조작 대상은 최소 44px다.
- 바다·ASMR·토스 앱에서 `app/sea-navigation.css`의 같은 토큰과 스타일을 읽는다. 모바일 안전 영역과 가로 화면을 고려하며, 긴 내용은 하단바 위에서만 스크롤한다.
- 실제 게임·시작 안내·디자인 시스템 검토 화면이 같은 탭 컴포넌트를 사용한다. 기존 개별 CSS의 전체 통합과 모든 상세 화면의 타이포그래피 감사는 이후 단계다.
