# 눈 모드의 잔잔한 캐롤

2026-11-23. 사용자의 ‘눈 모드에서 크리스마스까지만 작은 캐롤’ 요청을 적용한다. 썰매 효과음 후보 재선정과는 별도 기능이다.

## 재생 규칙

- 게임의 눈 모드에서 바다 소리를 직접 켠 경우에만 재생한다. 캐롤 기능이 바다 소리를 강제로 켜지 않는다.
- 한국 시간으로 매년 11월 1일부터 12월 25일 23:59:59까지 제공한다. 현재 시즌은 2026년 12월 26일 00:00에 종료한다. 1월이나 여름에 눈 모드를 선택해도 캐롤은 재생하지 않는다.
- 마지막 4초는 줄어들고, 종료 시각에는 정지한다. 날짜 판단은 기기 시각을 한국 시간으로 변환하며 별도 서버 요청을 하지 않는다.
- 캐롤 채널의 목표 음량은 전체 음량 설정의 20%다. 처음에는 서서히 켜지며 날씨가 바뀌면 서서히 사라진다.
- 음소거·캐롤 제외·수면·광고·앱 숨김 상태에서는 즉시 음량을 0으로 하고 일시 정지한다. 게임에서 ASMR 화면으로 이동하면 음악 채널을 정리한다.
- 도감·보상음의 기존 감쇠 이벤트를 함께 받아 캐롤도 잠시 작아진다.
- 데스크톱 하단의 ‘캐롤 포함/제외’, 모바일 설정의 ‘잔잔한 캐롤 함께 듣기’로 바다 소리와 따로 선택한다. 설정은 기기에 저장하고 토스의 기존 저장 백업에도 포함한다.
- 캐롤 파일을 불러오지 못해도 파도 소리는 유지한다. 실패 후 60초간 재시도하지 않고 설정에서 안내한다.

## 곡과 출처

곡: **고요한 밤 / Silent Night (Stille Nacht)**. 작곡 Franz Xaver Gruber (1787–1863).

원곡 악보의 퍼블릭 도메인 자료: https://www.mutopiaproject.org/ftp/GruberFX/stille_nacht/stille_nacht-let.pdf (Mutopia-2008/02/19-1295). 해당 자료는 배포·수정·연주를 허용한다고 표기한다.

이번 파일은 타인의 녹음이나 샘플을 내려받은 것이 아니다. 공개된 원곡 선율에 서비스용 반주·편곡과 부드러운 피아노 톤을 직접 합성한 **76.2초 연주**다. 피아니스트의 실연 녹음이나 외부 무료 사이트 음원을 적용했다고 표기하지 않는다.

- 재현 스크립트: `scripts/audio/create-winter-carol.py`.
- 음원: `public/audio/seasonal/silent-night-v1.mp3`, 약 1.22MB.
- 원전·제작 방식·해시·길이: 같은 폴더의 `manifest.json`.
- UI의 음원 출처에도 작곡자·원전·직접 합성 제작 방식을 안내한다.

## 검증

`tests/winter-carol.test.mjs`는 한국 자정의 경계, 연간 시즌, 수면·명시적 재생·음소거·볼륨·보상 감쇠, 생성 음원의 해시와 헤드룸을 검사한다. GitHub CI에 포함한다. 토스 번들에도 같은 MP3가 포함되는지 해시로 확인한다.

`tests/browser/winter-carol.cjs`에서 실제 MP3 디코딩과 작은 음량, 첫 재생 전 파일 요청 없음, 캐롤만 끄기·전체 음소거·날씨·광고·숨김·수면 전환, 한국 12월 25일→26일 자동 종료, 기기 저장, 종료 후 새 방문 시 음원 요청 없음, 모바일 조작 및 선택 음원 실패 시 바다 소리 유지·재시도 제한을 확인했다.

기존 ASMR 흐름은 별도로 회귀 검사한다. 실제 토스 기기에서 이어폰·통화·화면 잠금과 청감 확인은 기존의 별도 검증 항목이다.
