## 음량·재생 정책

배경 루프는 -24 LUFS 목표, 효과음은 -21 LUFS 목표로 정규화한 뒤 리미터와 MP3 인코딩을 적용했다. 실제 재생 음량은 마스터와 음원별 게인을 추가 적용한다. 원본 음원에 담긴 짧은 소리의 크기를 모두 같은 청감이라고 단정하지 않는다. 브라우저 디코딩 및 수치 검사는 청음 검수나 실기기 청취를 대체하지 않는다.

루프는 1초 경계를 수치 교차 편집하고 단발음에는 시작·끝 페이드를 적용한다. 사용자 허용 전에는 음원을 요청·재생하지 않는다. 일반 조리·수집 행동이 꺼진 소리를 강제로 켜지 않는다. 시작 안내의 명시적 소리 버튼에서만 시작음 → 시작 음악을 순서 재생한다. 마스터 음소거는 효과·음악·파도·비·물살·모닥불을 함께 멈춘다. 토스 광고/백그라운드에서는 일시 중지하고 허용한 상태에서 복귀한다.

새로운 종류는 도감 축하음, 기존 종류 추가는 수집음이다. 같은 개체 재획득·저장 데이터 복원·중복 뗏목 획득은 축하음을 다시 내지 않는다. 왕관/부적은 보물 소리를 사용한다. 보물·성취·도감·장비·수집 순서로 한 보상 채널의 우선순위를 정하며 하위 보상이 상위 소리를 덮지 않는다. 큰 보상/시작음 중에는 배경 음량을 낮춘다.

낚시·이동·날씨·자리 판정을 위해 서버 호출을 추가하지 않는다. 기존 상태를 로컬 200ms 타이머에서 확인한다. 입질은 캐스팅별 1회, 발걸음은 약 620ms 간격, 천둥은 비 옵션을 켠 뒤 최소 45초, 이후 65~105초 간격이다. 물살 루프는 사용자 본인의 실제 항해/뗏목 이동 중에만 사용한다. 음원 실패는 30초 대기로 매 프레임 재요청하지 않는다.

## 출처

기본 파도는 simong1006 / CC BY 4.0, 밤바다는 BonnyOrbit / CC0, 노 젓기는 Fenodyrie / CC0로 기존 링크와 대조했다. 일반 수집음은 파일 내 메타데이터의 Synthetic Waterdrop / Porphyr / CC BY 3.0를 보존하여 출처에 추가했다. 모래 발걸음은 메타데이터의 Nox_Sound 제작자 이름을 표기한다. 나머지 제공 파일의 원본 링크·라이선스는 별도로 확인되지 않았으며 임의로 CC0 또는 상업 이용 검증 완료로 표시하지 않는다. 정식 유통 전 원본 링크와 라이선스 기록을 보완할 항목이다.

앱 설정의 음원 출처에서 21개 파일과 확인된 제작자·원본 링크·라이선스·편집 내역을 표시한다. 공개 manifest에는 원본 파일명·SHA256·처리 구간·산출물 해시를 남기고 원본 대용량 파일은 Git에 넣지 않는다.

## 모닥불과 파도의 거리 전환 — 2026-11-10

기존 모닥불 위치·불 상태·가시성 판정을 유지하면서 10 좌표 단위 바깥에서는 파도를 기본 음량으로, 1.5 안쪽에서는 모닥불을 전면으로 들려준다. 중간 구간은 smoothstep으로 연결하며 가까운 자리의 파도는 약 12%까지 줄인다. 불소리는 마스터 음량의 최대 95%를 목표로 거리 제곱근 곡선과 100ms 음량 보간을 사용한다. 두 트랙은 같은 마스터 음량과 음소거 설정을 따른다.

파도 감쇠는 모닥불의 실제 재생 성공과 현재 음량에서 계산한 로컬 신호를 받아 적용한다. 불이 꺼짐·멀어짐은 서서히 불소리를 줄인 뒤 파도를 복원한다. 전체 음소거는 즉시 멈추며, 불소리 파일이 실패하거나 재생하지 못하면 파도를 감쇠하지 않는다. 서버 요청·새 타이머는 추가하지 않고 기존 음량 타이머를 재사용한다.

브라우저의 실제 오디오 요소로 먼 거리 → 중간 → 가까이 → 먼 거리의 상호 전환, 꺼진 불, 전체 음소거, 불소리 다운로드 실패 시 파도 유지까지 확인했다. 테스트 전용 React 장면은 실행 후 public에서 제거하며 제품 빌드에 포함하지 않는다. 거리/음량 곡선 자동 검사 1개를 추가하여 전체 자동 회귀는 49개다. 실제 기기 청감은 별도 확인한다.
